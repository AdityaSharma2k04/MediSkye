**Project Title:** MediSkye: Intelligent Medical Report Analysis System using Retrieval-Augmented Generation (RAG)

**Project Details:** MediSkye is an AI-powered healthcare assistant designed to translate complex medical diagnostic reports into plain English. The system utilizes a Multimodal RAG pipeline to process text-based PDFs and visual medical imagery. Operating on a decoupled FastAPI backend and Streamlit dashboard, it incorporates Google Gemini 3.6 API, FAISS vector store, and OpenCV/CLAHE for image enhancement, acting as a reliable preliminary triage tool to reduce patient anxiety.
